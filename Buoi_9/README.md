# Buổi 9: Prefab, animation và scoring

[Mục lục](../README.md) · [Báo cáo nội dung còn thiếu](../NOI_DUNG_CON_THIEU.md#buoi-9)

## Nội dung theo Google Sheet

- Prefab: tạo, edit, Prefab Variant, unpack
- Instantiate(prefab, position, rotation) — spawn object
- Destroy(gameObject, delay) — xoá object
- Animator Controller: tạo State, Transition, Parameter (bool, float, trigger)
- Animator.SetTrigger, SetBool, SetFloat từ script
- Animation Clip: tạo animation đơn giản trong Unity
- OnDisable dùng trong MonoBehaviour — unsubscribe event, dọn dẹp
- Scoring đơn giản: biến static int score tạm thời (sau sẽ refactor)

## Tài liệu hiện có

Chưa có file tài liệu chi tiết từ repo nguồn cho buổi này. Thư mục `Tai_lieu_cu_the` được giữ bằng `.gitkeep`.

Chưa có file BTVN được chuyển từ nguồn cho buổi này. Cột BTVN trong Sheet hiện để trống; chưa xác định yêu cầu bài tập.

## Phần cần bổ sung

- Chưa có bài Prefab, Prefab Variant, unpack, Instantiate và Destroy có delay.
- Chưa có bài Animator Controller (state/transition/parameter), SetTrigger/SetBool/SetFloat và Animation Clip.
- Chưa có ví dụ OnDisable để unsubscribe/dọn dẹp và scoring bằng static int score.

Phần lộ trình và danh sách thiếu ở đây là ghi chú tổ chức mới; không phải bài giảng bổ sung.
