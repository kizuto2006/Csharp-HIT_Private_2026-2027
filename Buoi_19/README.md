# Buổi 19: Player Settings và build game

[Mục lục](../README.md) · [Báo cáo nội dung còn thiếu](../NOI_DUNG_CON_THIEU.md#buoi-19)

## Nội dung theo Google Sheet

- Player Settings
  + Tên game, Company Name
  + Icon ứng dụng (các kích thước)
  + Splash Screen: thêm logo, chỉnh màu nền, thời gian hiển thị
  + Default Screen Resolution, Fullscreen Mode
- Build Settings
  + Thêm scene đúng thứ tự (index 0 = scene đầu tiên load)
  + Development Build — bật để xem log trên build
- Build cho PC (Windows)
  + Platform: Standalone Windows x64
  + Build ra thư mục, chạy file .exe
- Build cho WebGL
  + Cài module WebGL trong Unity Hub
  + Compression: Gzip vs Brotli
  + Memory size: 256MB mặc định, tăng nếu cần
  + Template: Default vs Minimal
  + Upload lên itch.io — Public, embed WebGL

## Tài liệu hiện có

Chưa có file tài liệu chi tiết từ repo nguồn cho buổi này. Thư mục `Tai_lieu_cu_the` được giữ bằng `.gitkeep`.

Chưa có file BTVN được chuyển từ nguồn cho buổi này. Cột BTVN trong Sheet hiện để trống; chưa xác định yêu cầu bài tập.

## Phần cần bổ sung

- Chưa có bài Player Settings: tên game, Company Name, icon, Splash Screen, resolution và Fullscreen Mode.
- Chưa có bài Build Settings: thứ tự scene và Development Build.
- Chưa có hướng dẫn build Windows x64 và chạy .exe.
- Chưa có hướng dẫn module/build WebGL, compression Gzip/Brotli, memory, template và upload/embed lên itch.io.

Phần lộ trình và danh sách thiếu ở đây là ghi chú tổ chức mới; không phải bài giảng bổ sung.
