# Buổi 10: UI và HUD

[Mục lục](../README.md) · [Báo cáo nội dung còn thiếu](../NOI_DUNG_CON_THIEU.md#buoi-10)

## Nội dung theo Google Sheet

- Canvas: Screen Space — Overlay vs Camera vs World Space
- Rect Transform: Anchor, Pivot, Stretch — hiểu bố cục responsive
- Image: Source Image, Color, Fill Amount (dùng cho HP bar)
- Button: OnClick event trong Inspector và trong code
- Slider: Min, Max, Value, dùng cho volume
- TextMesh Pro: tại sao dùng thay Text cũ, import TMP Essential Resources
- TMP_Text.text = value.ToString() — cập nhật text từ code
- Raycast Target — tắt khi không cần thiết để tối ưu
- Hiển thị HP bar, Shield bar, điểm số, số wave lên HUD
- Canvas Group — fade in/out cả nhóm UI

## Tài liệu hiện có

Chưa có file tài liệu chi tiết từ repo nguồn cho buổi này. Thư mục `Tai_lieu_cu_the` được giữ bằng `.gitkeep`.

Chưa có file BTVN được chuyển từ nguồn cho buổi này. Cột BTVN trong Sheet hiện để trống; chưa xác định yêu cầu bài tập.

## Phần cần bổ sung

- Chưa có bài Canvas (Overlay/Camera/World Space) và Rect Transform (Anchor/Pivot/Stretch).
- Chưa có bài Image/Fill Amount, Button/OnClick, Slider và TextMesh Pro/TMP Essential Resources/TMP_Text.
- Chưa có hướng dẫn Raycast Target, HUD (HP/Shield/điểm/wave) và Canvas Group fade.

Phần lộ trình và danh sách thiếu ở đây là ghi chú tổ chức mới; không phải bài giảng bổ sung.
