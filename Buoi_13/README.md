# Buổi 13: DOTween, Animator nâng cao và âm thanh

[Mục lục](../README.md) · [Báo cáo nội dung còn thiếu](../NOI_DUNG_CON_THIEU.md#buoi-13)

## Nội dung theo Google Sheet

- Giới thiệu về DOTween Framework
- Animator nâng cao
  + Blend Tree — nhiều animation blend theo float
  + Animation Event — gọi function C# từ keyframe
  + AnimatorOverrideController — đổi clip runtime
- Audio System
  + AudioSource: PlayOneShot, clip, volume, loop
  + AudioListener — chỉ cần 1 trên scene
  + BGM vs SFX — 2 AudioSource riêng biệt
  + Đọc AudioManager.cs — Singleton quản lý tất cả âm thanh
