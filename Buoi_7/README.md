# Buổi 7: GameObject, Transform và các component 2D

[Mục lục](../README.md) · [Báo cáo nội dung còn thiếu](../NOI_DUNG_CON_THIEU.md#buoi-7)

## Nội dung theo Google Sheet

- Transform: Position, Rotation, Scale — hệ tọa độ 2D Unity
- Space.World vs Space.Self
- SpriteRenderer: import Sprite, Sorting Layer, Order in Layer
- Rigidbody2D: Dynamic vs Kinematic, Gravity Scale, Constraints
- Collider2D: BoxCollider2D, CircleCollider2D
- Collision vs Trigger — sự khác nhau, cách chọn
- Viết MonoBehaviour đầu tiên: tạo file script, attach vào GameObject
- [SerializeField] — hiển thị field private trên Inspector
- [Header("...")] — nhóm field trong Inspector
- GetComponent<T>() — lấy component trên cùng GameObject
- Layer: tạo Layer, gán cho GameObject

## Tài liệu hiện có

Chưa có file tài liệu chi tiết từ repo nguồn cho buổi này. Thư mục `Tai_lieu_cu_the` được giữ bằng `.gitkeep`.

Chưa có file BTVN được chuyển từ nguồn cho buổi này. Cột BTVN trong Sheet hiện để trống; chưa xác định yêu cầu bài tập.

## Phần cần bổ sung

- Chưa có tài liệu Transform (Position/Rotation/Scale), hệ tọa độ 2D và Space.World / Space.Self.
- Chưa có hướng dẫn import sprite, SpriteRenderer, Sorting Layer / Order in Layer.
- Chưa có tài liệu Rigidbody2D, Dynamic/Kinematic, Gravity Scale, Constraints, BoxCollider2D, CircleCollider2D và Collision/Trigger.
- Chưa có bài tạo/attach MonoBehaviour, `[SerializeField]`, `[Header]`, `GetComponent<T>()` và Layer.

Phần lộ trình và danh sách thiếu ở đây là ghi chú tổ chức mới; không phải bài giảng bổ sung.
